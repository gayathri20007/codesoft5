1. Introduction

The Contact Book is a Python-based application developed as part of my CodeSoft Python Programming Internship.

The main purpose of this project is to create a simple contact management system that allows users to store, manage, search, update, and delete contact information.

In our daily lives, we need to save and manage contact details such as names, phone numbers, and email addresses. This application makes contact management easier and more organized.

This project demonstrates the practical implementation of Python programming concepts through a real-world application.

3. Project Description

The Contact Book is a simple application developed using Python programming language.

It provides different options to manage contact details. Users can enter information such as name, phone number, and email address.

The application allows users to add new contacts, display saved contacts, search for particular contacts, update existing information, and delete contacts when they are no longer needed.

The program uses Python concepts such as dictionaries, lists, functions, loops, and conditional statements to perform different operations.

4. Features of the Project
1. Add Contact

Allows users to add new contact details, including name, phone number, and email address.

2. View Contacts

Displays all the contacts stored in the Contact Book.

3. Search Contact

Allows users to search for a particular contact using the contact name or other supported details.

4. Update Contact

Allows users to modify existing contact information, such as phone numbers and email addresses.

5. Delete Contact

Allows users to remove unwanted contacts from the Contact Book.

6. User-Friendly Interface

Provides a simple menu-driven interface that makes the application easy to use.

7. Contact Management

Helps users maintain and organize their contact information efficiently.

7. Working Process

Step 1: Start the Python program.

Step 2: Display the Contact Book menu.

Step 3: Ask the user to select an operation.

Step 4: If the user selects Add Contact, collect the contact details and save them.

Step 5: If the user selects View Contacts, display all saved contacts.

Step 6: If the user selects Search Contact, find and display the requested contact.

Step 7: If the user selects Update Contact, modify the existing contact details.

Step 8: If the user selects Delete Contact, remove the selected contact.

Step 9: Allow the user to continue performing operations until they choose to exit.

Step 10: End the program.
